# Time-travel-cook-
Descripción

TimeTravel Cook es una aplicación interactiva que combina cocina, historia, cultura y tecnología. Permite a los usuarios ingresar los ingredientes que tienen en casa y recibir recomendaciones de recetas personalizadas mediante inteligencia artificial.
 Experiencia

La experiencia se vuelve única porque personajes históricos viajan al mundo moderno y guían al usuario durante el proceso de cocina, reaccionando con humor a la tecnología actual mientras enseñan datos culturales e históricos.

 ¿Cómo funciona?

* El usuario ingresa sus ingredientes
* La IA recomienda recetas
* Un personaje histórico guía el proceso
* Se puede cocinar de forma virtual o presencial
* El usuario sube una foto del plato
* Recibe una calificación divertido  Blockchain

El progreso del usuario (recetas, logros y experiencias culturales) se guarda en blockchain como un “pasaporte cultural digital”.


🌱 Impacto y ODS

ODS 4 — Educación de calidad

TimeTravel Cook transforma el aprendizaje tradicional en una experiencia interactiva, utilizando tecnología, gamificación y personajes históricos para enseñar cultura e historia de forma dinámica y atractiva para los jóvenes.

ODS 12 — Producción y consumo responsable

La aplicación fomenta el uso de ingredientes disponibles en casa, ayudando a reducir el desperdicio de alimentos y promoviendo hábitos de consumo más responsables.

⸻

🎯 Objetivo

Reducir el desperdicio de alimentos, fomentar la creatividad culinaria y transformar el aprendizaje en una experiencia interactiva y entretenida.
